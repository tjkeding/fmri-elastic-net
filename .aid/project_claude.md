# Project: Activation/Connectome Predictive Modeling with an Elastic Net

**Core Objective:** A free-standing pipeline for implementing activation or connectome predictive modeling with an elastic net. The pipeline offers user-specified flexibility around 'analysis type' (regression, classification), 'analysis mode' (predict [LASSO + Ridge] or correlate [Ridge-heavy]), covariate inclusion, and dimensionality reduction options. Model performance is evaluated and feature analysis is implemented.
